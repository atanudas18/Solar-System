# ✨ Overview

**Solar System** is an immersive educational web application that lets users explore the Sun and all eight planets in an interactive 3D environment.

Designed with **Three.js**, the project combines scientific information with elegant animations to create a premium space exploration experience directly inside the browser.

Whether you're a student, educator, or space enthusiast, this project offers an engaging way to learn about our Solar System.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/atanudas18/Solar-System.git
```

Open project

```bash
cd Solar-System
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Open browser

```
http://localhost:5173
```
